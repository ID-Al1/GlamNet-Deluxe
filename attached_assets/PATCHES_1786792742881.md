## Patch 3 — Record when the artist was actually paid

**File:** `lib/db/src/schema/appointments.ts`

Add to the appointments table, after `platformFeeAmount`:

```ts
  // The RATE, not just the amounts. Without this you cannot tell, six months
  // from now, which bookings were taken at 18% and which at some later rate.
  platformFeePercent: real("platform_fee_percent").notNull().default(18),

  // "released" means cleared for payment. These record that money actually
  // left the account, which is what the 24-hour promise is measured against.
  payoutDueAt: timestamp("payout_due_at"),
  paidOutAt: timestamp("paid_out_at"),
  payoutReference: text("payout_reference"),
```

And add the missing foreign key. Change:

```ts
  stylistId: text("stylist_id").notNull(),
```

to:

```ts
  stylistId: text("stylist_id").notNull().references(() => stylistProfilesTable.id),
```

with `import { stylistProfilesTable } from "./stylists";` at the top.

**Careful:** if any existing appointment rows point at a profile that no longer exists, adding the foreign key will fail. Check for orphans first:

```sql
SELECT a.id FROM appointments a
LEFT JOIN stylist_profiles p ON a.stylist_id = p.id
WHERE p.id IS NULL;
```

Delete or repair anything that comes back, then add the constraint.

**Then**, wherever `payoutStatus` is set to `"released"`, also set `payoutDueAt` to 24 hours from that moment. Add a `markPaidOut` step that sets `paidOutAt` and `payoutReference` when you actually pay her.

import { calculateRepScore, calculateTier } from "../lib/reputation";

const [p] = await db.select().from(stylistProfilesTable)
  .where(eq(stylistProfilesTable.id, appt.stylistId));

const completedJobs = p.completedJobs + 1;
const repScore = calculateRepScore({
  completedJobs,
  averageRating: p.rating,
