Do not build or propose building artist subscriptions (R99 Basic, R199 Pro) until 50 artists have been verified on Bonisa. Rule set by Alwande on 2026-10-19.

**Why:** the First 50 verified artists come first. Charging before the network has proof of value risks losing them.
**How to apply:** skip subscriptions in any roadmap or build queue. Count verified artists from stylist_profiles where verified is true. Remind Alwande when the count reaches 50.
